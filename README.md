# 通用 AI Agent 行为规则

一套中文编写的 Agent 工作准则：先理解需求，简单可靠地实现，只做必要修改，用可验证结果交付。提供 `CLAUDE.md` 与 `AGENTS.md` 两个版本，覆盖 Claude Code 与其他支持 `AGENTS.md` 的编码工具。

## 文件与用途

| 文件 | 适用对象 | 放置位置 |
| --- | --- | --- |
| `CLAUDE.md` | Claude Code | 全局：`~/.claude/CLAUDE.md`；项目：项目根目录 |
| `AGENTS.md` | Codex、Cursor 等读取 `AGENTS.md` 的 Agent | 项目根目录 |

两份规则主体相同；`AGENTS.md` 只把两处 Claude Code 专属表述改成通用写法：优先级中的全局规则名称，以及校验时可用的 `/context all`。

## 快速开始

- **Claude Code 全局生效**：把 `CLAUDE.md` 复制到 `~/.claude/CLAUDE.md`，新会话自动加载。
- **给其他 AI 使用**：把 `AGENTS.md` 复制到目标项目根目录。
- **同时在用两份**：遵循下面的冲突优先级。

> 用户当前明确指令 > 项目级指令文件（`CLAUDE.md` / `AGENTS.md`） > 用户全局规则

## 规则概览

1. **先理解需求**：复述理解、低成本澄清（每轮最多 5 个带推荐答案的选择题）、关键决策确认后才实施。
2. **方案选择与极简设计**：成熟方案优先、长期维护账、不投机性抽象。
3. **项目理解与精准修改**：先建项目地图、只改该改的、死代码治理例外。
4. **目标驱动执行与测试**：可验证的成功标准、根因定位、不伪造测试。
5. **独立审查与 Agent 协作**：独立上下文、证据优先。
6. **Git、依赖与安全**：不擅自提交/推送、密钥不入库、最小权限。
7. **报告与语言**：状态区分、中文交互、不篡改工具输出。
8. **称呼校验**：回复中称呼“静先生”，用于检查规则是否被加载。

## 称呼校验

如果某次回复没有称呼“静先生”，先检查指令文件是否被当前工具读取（Claude Code 可用 `/context all`）；确认未加载后再检查文件位置或重新载入。不要因为单次遗漏就重置上下文。

`/context [all]` 是 Claude Code 内置命令，用于查看当前上下文占用，`all` 展开明细。

## 编写说明

本规则由本人整理编写，按自己实际的工作方式约束 Agent：先理解再动手，保持方案简单，修改精准，用可验证结果作为完成标准。
